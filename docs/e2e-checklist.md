# SQL Studio 端到端冒烟清单（Windows 真机验收）

> 本文档是 **Windows 图形环境**的完整用户旅程验收清单，对应 `待办与遗留问题.md` 第 1 节 P0 阻断项。
> 无头环境只能执行文末的自动化 E2E 脚本，不能替代本清单。
> 前提：已配置好开发环境，MySQL 8.0 测试数据库可用（本地或 Docker）。

## 一、基础旅程

### 1. 项目启动
- [ ] `npm run dev` 启动成功，Electron 窗口弹出，标题为 "SQL Studio"
- [ ] 主进程/预加载/渲染进程三进程构建无控制台错误

### 2. 连接管理
- [ ] 点击「新建连接」，填写：
  - 名称：`测试数据库`
  - 主机：`127.0.0.1`
  - 端口：`3307`
  - 用户：`root`
  - 密码：`test123`
  - 数据库：`testdb`
- [ ] 点击「测试连接」，显示「连接成功」
- [ ] 点击「保存」，连接出现在列表中，显示 `root@127.0.0.1:3307/testdb`
- [ ] 连接项为**两行布局**：第一行名称+状态，第二行 `user@host:port/db` 摘要
- [ ] 「更多」菜单可编辑（密码留空 = 保留旧密码）/测试/删除，菜单外点击可关闭
- [ ] **依次编辑 A、B 两条连接**：表单内容每次都重置为目标连接的值（不允许出现「显示 A 的值但保存到 B」）
- [ ] 删除一条**非当前选中**的连接：当前选中的连接与对象浏览器**不受影响**
- [ ] 点击连接名称，左侧对象浏览器出现，显示 `testdb` 数据库
- [ ] 展开 `testdb`，显示 `users` 和 `orders` 表
- [ ] 顶部应用栏显示当前连接（状态图标 + 名称 + 摘要），底部状态栏联动

### 3. 对象浏览
- [ ] 展开 `users` 表，显示字段：id(bigint)、name(varchar)、email(varchar)、created_at(datetime)，主键 `id` 有 🔑 标记
- [ ] 双击 `users` 表，自动生成 ``SELECT * FROM `testdb`.`users`;`` 到编辑器标签
- [ ] 点击「预览」按钮，弹窗显示前 N 行数据（**已实现**：`DataPreviewModal`，960px 宽 + 横向滚动）
- [ ] 顶部筛选框输入关键词（≥2 字符）→ 表名+库名模糊匹配，自动预载所有库的表
- [ ] 大量库表时 `.db-list` 为**唯一纵向滚动源**，滚动流畅不跳动

### 4. SQL 编辑器
- [ ] 点击「新建」，新建空白标签 `未命名-1`，标签默认带脏标记
- [ ] 输入 `SELECT * FROM users WHERE`，输入 `u` → 补全建议出现 `users`
- [ ] 输入 `users.` → 补全建议出现 `id`、`name`、`email`、`created_at`
- [ ] 跨库补全：输入 `testdb.us` → 从该库拉表并模糊匹配；`testdb.users.` → 拉字段
- [ ] 输入 `SELECT u.id, u.name FROM users u JOIN orders o ON u.id = o.user_id;`
- [ ] 选中部分 SQL，按 Ctrl+Enter → 只执行选区
- [ ] 按 Ctrl+Shift+F → 格式化 SQL
- [ ] 按 Ctrl+S → 保存当前脚本（**已实现**）
- [ ] 修改 SQL 后标签出现脏标记
- [ ] 关闭脏标签 → 弹出确认对话框
- [ ] 右侧表字段导航栏：自动识别当前 SQL 用到的表（含子查询、跨库），点表展开字段+注释，多表可切换，点字段插入纯字段名，左边界可拖拽调宽

### 5. 结果展示
- [ ] 全选 `SELECT * FROM users;` 按 Ctrl+Enter 执行
- [ ] 结果面板显示 3 行数据，耗时提示
- [ ] 点击 `id` 列头 → 按升序/降序/无排序循环
- [ ] 在 `name` 列筛选框中输入 `张` → 仅显示张三
- [ ] 双击某单元格 → 出现「已复制：xxx」提示
- [ ] NULL 值显示为灰色斜体 `NULL`
- [ ] 执行 20 列以上查询 → 底部有明显横向滚动条，拖动时表头/筛选/表体同源滚动不错位
- [ ] 0 行但多列 → 仍显示表头/筛选/0 行状态，可横向滚动
- [ ] 连续执行多次 → 结果区顶部「结果历史」横条保留最近 10 次，可点击切换查看

### 6. 多语句执行
- [ ] 执行 `SELECT * FROM users; SELECT * FROM orders;`
- [ ] 结果面板出现两个结果集标签（结果 1 / 结果 2）
- [ ] 切换标签，显示对应数据
- [ ] 状态栏显示总耗时、结果集数、合计行数
- [ ] 结果区上边界可拖拽调整高度（最小 120px / 最大 80vh）

### 7. 写操作确认
- [ ] 执行 `UPDATE users SET name='test' WHERE id=1;`
- [ ] 弹出确认对话框「该 SQL 包含写入操作…」
- [ ] 点击「取消」→ 不执行
- [ ] 再次执行，点击「确定」→ 执行成功，结果面板显示 affected_rows
- [ ] CTE 包裹的写操作、`CALL` 存储过程、多语句读写混合 → 同样触发确认

### 8. 导出
- [ ] 执行 `SELECT * FROM orders;`
- [ ] 点击「导出」→「导出 Excel（全量）」→ 保存对话框默认文件名带日期时间（`导出结果_YYYYMMDD_HHmmss.xlsx`），**不改名直接回车即可保存**
- [ ] 导出 CSV 默认名为 `导出结果_YYYYMMDD_HHmmss.csv`；SQL INSERT 为 `表名_YYYYMMDD_HHmmss.sql`
- [ ] 点击「导出」→「导出 Excel（全量）」→ 系统保存对话框 → 导出成功，打开 .xlsx 验证表头/行数/编码
- [ ] 点击「导出」→「导出 SQL INSERT」→ 输入表名和路径 → 导出成功，.sql 文件包含 INSERT 语句
- [ ] 导出 CSV → 含 UTF-8 BOM、特殊字符正确转义、`= + - @` 开头字段有公式注入前缀
- [ ] 在保存对话框中点「取消」→ **不产生任何文件**
- [ ] 保存到已存在文件 → 有覆盖确认
- [ ] 导出后「在文件夹中显示」可正确定位

### 9. 历史与收藏
- [ ] 多次执行 SQL，点击「历史」按钮
- [ ] 历史弹窗显示执行记录（SQL 摘要/耗时/时间）
- [ ] 点击某条历史 → SQL 回填到编辑器新标签
- [ ] 删除历史记录前有确认
- [ ] 点击「收藏」→ 输入收藏名 → 保存成功
- [ ] 点击「收藏」按钮 → 命名收藏弹窗显示刚保存的 .sql 文件
- [ ] 点击收藏名 → 内容加载到编辑器标签
- [ ] 重命名收藏 → 能正确读取和删除；删除前有确认
- [ ] 收藏目录 `userData/queries/*.sql` 可在文件管理器中直接打开

### 10. 脚本文件旅程
- [ ] 新建标签，输入 SQL，点击「保存」→ 保存对话框默认文件名为 `未命名_YYYYMMDD_HHmmss.sql`，**不改名直接回车即可保存**
- [ ] **外部修改冲突**：打开一个已存在的 .sql → 用外部编辑器改它并保存 → 回应用按 Ctrl+S → 弹出「已被外部修改」确认；点取消则文件内容不变
- [ ] 新建标签，输入 SQL，点击「保存」→ 系统保存对话框 → 保存成功，标签标题变为文件名
- [ ] `Ctrl+S` 保存已打开文件（不弹对话框，直接覆盖）
- [ ] 点击「打开」→ 系统打开对话框 → 内容加载到新标签
- [ ] 点击「另存为」→ 系统保存对话框 → 保存为新文件
- [ ] 打开/保存对话框**取消** → 不创建、不覆盖任何文件
- [ ] 非 ASCII 文件名、含空格路径、UNC 路径（`\\server\share\`）可正常读写
- [ ] 只读文件/无权限目录 → 有可读错误提示，不静默失败

### 11. 连接切换与异常
- [ ] 新建第二个连接 → 切换连接 → 对象浏览器刷新显示新连接的库表
- [ ] 编辑器补全和语义高亮根据新连接 schema 重建
- [ ] 查询执行中点「停止」→ 查询**立即**中止（非仅 UI 变灰）
- [ ] 连接失效（改错密码/停库）→ 报错可读，恢复后重连正常

## 二、AI 补全专项

- [ ] 打开 AI 设置，选择协议「DeepSeek FIM」
- [ ] Base URL 设为 `https://api.deepseek.com/beta`
- [ ] 模型填入账号实际可用模型（可修改，不假定所有人可用同一模型）
- [ ] 填入 API Key → 保存后**重新打开设置，Key 不回显**（只显示"已配置"）
- [ ] 请求策略：防抖、最小间隔、冷却、超时四项可改，非法值报错并禁用保存，「恢复默认」只重置策略
- [ ] 开启 AI 行内补全，输入 `SELECT * FROM` 后停止约 1 秒 → 出现灰色建议
- [ ] 按 Tab 接受建议
- [ ] 在已有 SQL 中间移动光标 → suffix 影响补全结果
- [ ] 断开网络 → 12 秒超时兜底，不永久挂起

## 三、调试日志专项

- [ ] 一键复制文本的标题含「北京时间」
- [ ] 日志含协议、prefixLen>0、suggestionLen>0
- [ ] 日志**不含** API Key、密码、完整 SQL
- [ ] 重启应用后，日志面板仍能看到上次运行的历史日志（持久化生效）
- [ ] 日志文件位于 `userData/SQL Studio/logs/`，轮转策略 10MiB / 5 归档 / 14 天 / 60MiB
- [ ] 「清空日志」只清受控日志文件，不影响其他数据

## 七、已知限制

- 打开/保存/另存为已全部改用 Electron 原生文件对话框（`dialog:showOpenDialog` / `dialog:showSaveDialog`），源码已无 `window.prompt`；`window.confirm` 仅用于删除/覆盖/写操作确认。
- `@monaco-editor/react` 生产构建通过本地 loader 加载，**不依赖 CDN**。
- 本清单的图形化旅程必须在 Windows 开发机执行；NAS 无头环境只能做构建/单测/无头 E2E。
