# SQL Studio 端到端冒烟清单

> 本文档记录完整用户旅程的冒烟测试步骤。
> 前提：已配置好开发环境，MySQL 8.0 测试数据库可用（本地或 Docker）。

## 测试环境

| 项目 | 值 |
|---|---|
| 数据库 | MySQL 8.0 |
| 主机 | 127.0.0.1 |
| 端口 | 3307 |
| 用户名 | root |
| 密码 | test123 |
| 数据库 | testdb |
| 测试表 | users（3 行）、orders（4 行） |

## 冒烟步骤

### 1. 项目启动
- [ ] `npm run dev` 启动成功，Electron 窗口弹出，标题为 "SQL Studio"
- [ ] 主进程/预加载/渲染进程三进程构建无控制台错误

### 2. 连接管理
- [ ] 点击「新建连接」，填写：
  - 名称：`测试数据库`
  - 主机：`127.0.0.1`
  - 端口：`3307`
  - 用户：`root`
  - 密码：`test123`
  - 数据库：`testdb`
- [ ] 点击「测试连接」，显示「连接成功」
- [ ] 点击「保存」，连接出现在列表中，显示 `root@127.0.0.1:3307/testdb`
- [ ] 点击连接名称，左侧对象浏览器出现，显示 `testdb` 数据库
- [ ] 展开 `testdb`，显示 `users` 和 `orders` 表

### 3. 对象浏览
- [ ] 展开 `users` 表，显示字段：id(bigint)、name(varchar)、email(varchar)、created_at(datetime)，主键 `id` 有 🔑 标记
- [ ] 双击 `users` 表，自动生成 `SELECT * FROM `testdb`.`users`;` 到编辑器标签
- [ ] 点击「预览」按钮（待实现 → 显示前 N 行数据）

### 4. SQL 编辑器
- [ ] 点击「新建」，新建空白标签 `未命名-1`
- [ ] 输入 `SELECT * FROM users WHERE`，输入 `u` → 补全建议出现 `users`（表名青色）
- [ ] 输入 `users.` → 补全建议出现 `id`、`name`、`email`、`created_at`（字段名绿色）
- [ ] 输入 `SELECT u.id, u.name FROM users u JOIN orders o ON u.id = o.user_id;`
- [ ] 选中部分 SQL，按 Ctrl+Enter → 只执行选区
- [ ] 按 Ctrl+Shift+F → 格式化 SQL
- [ ] 修改 SQL 后标签出现脏标记（黄色圆点）
- [ ] 关闭脏标签 → 弹出确认对话框

### 5. 结果展示
- [ ] 全选 `SELECT * FROM users;` 按 Ctrl+Enter 执行
- [ ] 结果面板显示 3 行数据，耗时提示
- [ ] 点击 `id` 列头 → 按升序/降序/无排序循环
- [ ] 在 `name` 列筛选框中输入 `张` → 仅显示张三
- [ ] 双击某单元格 → 出现「已复制：xxx」提示
- [ ] NULL 值显示为灰色斜体 `NULL`

### 6. 多语句执行
- [ ] 执行 `SELECT * FROM users; SELECT * FROM orders;`
- [ ] 结果面板出现两个结果集标签（结果 1 / 结果 2）
- [ ] 切换标签，显示对应数据
- [ ] 状态栏显示总耗时、结果集数、合计行数

### 7. 写操作确认
- [ ] 执行 `UPDATE users SET name='test' WHERE id=1;`
- [ ] 弹出确认对话框「该 SQL 包含写入操作…」
- [ ] 点击「取消」→ 不执行
- [ ] 再次执行，点击「确定」→ 执行成功，结果面板显示 affected_rows

### 8. 导出
- [ ] 执行 `SELECT * FROM orders;`
- [ ] 点击「导出」→「导出 Excel（全量）」
- [ ] 输入路径，导出成功，打开 .xlsx 文件验证表头/行数/编码
- [ ] 点击「导出」→「导出 SQL INSERT」
- [ ] 输入表名 `orders` 和路径，导出成功，.sql 文件包含 INSERT 语句

### 9. 历史与收藏
- [ ] 多次执行 SQL，点击「历史」按钮
- [ ] 历史弹窗显示执行记录（SQL 摘要/耗时/时间）
- [ ] 点击某条历史 → SQL 回填到编辑器新标签
- [ ] 点击「收藏」→ 输入收藏名 → 保存成功
- [ ] 点击「收藏」按钮 → 命名收藏弹窗显示刚保存的 .sql 文件
- [ ] 点击收藏名 → 内容加载到编辑器标签
- [ ] 删除收藏 / 删除历史记录

### 10. 脚本保存
- [ ] 新建标签，输入 SQL，点击「保存」→ 输入路径 → 保存成功，标签标题变为文件名
- [ ] 修改后再次保存（快捷方式 Ctrl+S 待实现）
- [ ] 点击「打开」→ 输入路径 → 内容加载到新标签
- [ ] 点击「另存为」→ 输入新路径 → 保存为新文件

### 11. 连接切换
- [ ] 新建第二个连接（可配置另一个 MySQL 或重连测试库）
- [ ] 切换连接 → 对象浏览器刷新显示新连接的库表
- [ ] 编辑器补全和语义高亮根据新连接 schema 重建

- 导出路径同样使用 prompt，非系统对话框
- 此冒烟清单需在 Windows 开发机上执行（Electron GUI 冒烟需要图形环境）
